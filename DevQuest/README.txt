CODEQUEST — PROGRAMMING QUIZ PLATFORM

Included topics: Java, Python, C, C++, C#, JavaScript, HTML, CSS, SQL, React, Bootstrap, Node.js, PHP, Go, Rust, TypeScript, Database & SQL, Web Development.
Each topic has Easy, Medium and Hard levels with 50 question-bank entries per level. This is 18 topics × 3 levels × 50 = 2,700 entries.

FEATURES
- Choose topic, difficulty, and 10/20/30/50 questions
- English/Tamil toggle, Tamil questions and explanations, and approximate Tamil glosses for answer options (technical terms are retained in English)
- Timer, 50–50 lifeline, answer feedback and explanations
- Score, answer review, best score, recent history
- Responsive layout and dark mode
- Runs with plain HTML/CSS/JavaScript; no installation or backend needed

RUN
1. Extract the ZIP.
2. Open the folder in VS Code.
3. Open index.html in your browser, or use Live Server.

NOTE
Question entries are built from curated concept definitions with varied question wording. Some concepts repeat within a level with varied question wording to reach the requested 50 entries, and the Tamil option glosses are approximate. Review and expand the bank before using it for formal exams. Progress is stored only in the current browser. Real accounts and a shared leaderboard require a backend.
